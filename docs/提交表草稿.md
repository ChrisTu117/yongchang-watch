## 一句话简介（短）

守住永昌堡的城门，望向黑夜里的海——光照到哪里，才看得见敌人；守住一夜，舞龙拼出一个字。

## 作品简介（长）

明代温州永嘉场，乡人为抵御倭寇筑起永昌堡。你是敌台上的守望人：夜里海面一片漆黑，你望向哪里，光就照到哪里，守城单位只打得中被照亮的敌人〔C10〕。在十二座敌台上安排弓手、鸟铳和烽火，开关四座城门〔C16〕，开门迎进投奔的乡亲，他们会成为守城的民力。三个夜晚对应永昌堡史上的三次危机（1559 筑堡、1632 刘香围堡、1648 避乱者万人），史实均有出处〔C11〕。每守住一夜，就用龙湾宁村的拼字龙灯按笔顺描出一个字〔C12〕，最后拼成“天下太平”。

## Dora 平台兼容版本与运行说明（申请 Dora 开源社区奖）

- 兼容平台：LÖVE2D 11.5（主版本本身）；并提供 Dora SSR 1.10 入口〔C6〕，已在 Dora SSR 1.10.2 上实际运行〔C18〕〔M2〕
- 入口：仓库根目录 `init.lua`（Dora SSR 1.10 运行），或根目录 `main.lua`（LÖVE 11.5 运行）
- 依赖：无（字体、音效都在仓库里）
- 运行：打开 Dora SSR 1.10 后执行 `Dora --asset <Dora 资源目录> cli run -p <仓库目录>`，运行根目录 `init.lua`〔C18〕。`<Dora 资源目录>` 是含 `Script/Dev/cli.lua` 的目录，Windows 版就是 `Dora.exe` 所在的文件夹。Windows 和 macOS 版 Dora 的内置 IDE 会盖住游戏，`init.lua` 启动时自动收起；仍看到 IDE 时按 Ctrl+Shift+H 切到游戏〔C6〕
