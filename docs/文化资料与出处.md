# 文化资料与出处

游戏里每条史实后面都标了编号，对应下面的出处。资料都来自赛事官网 2026-11-21 公布的创作参考（https://2026gamejam.osgame.org/ 主题页“汤和信俗素材包”“永昌堡参考资料”）。游戏没有使用资料包里的任何图片，只依据文字设定玩法和剧情。

| 编号 | 游戏里的说法 | 出处 |
|---|---|---|
| [F1] | 王沛、王德组织乡兵抗倭，嘉靖三十七年（1558）先后殉国 | 《永昌堡十三进士与抗倭纪略》（王靖岳、王身康著，龙湾区委宣传部等编，官网 `yongchang-fort.pdf`）前言与导读：“嘉靖三十七年（1558）四月，梅头血战中，七十四岁的王沛壮烈殉国”；王德“十余日后……骂贼而死” |
| [F2] | 王叔杲放弃会试主持筑堡，“画城为十八号，每号五十丈”；城未竣倭寇突至；嘉靖三十八年（1559）落成；城门四座、水门四座、敌台十二座，东门瓮城；上河、下河；堡内百余亩农田 | 同书导读《铁血营建》一节：“画城为十八号，每号五十丈”“城堡周长二千六百八十八米，设城门四座、水门四座、敌台十二座，东门建有瓮城；引水入堡形成上河与下河……堡内规划百余亩农田，战时可供自给”“在工程最艰难的时刻，倭寇突至”；前言：“自嘉靖三十八年（1559）巍然落成” |
