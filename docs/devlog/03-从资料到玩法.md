# 开发者日志 03：把史料变成规则，而不是贴在墙上

2026-11-21

赛事给了两份参考资料：《永昌堡十三进士与抗倭纪略》（552 页）和汤和信俗素材包。文化传承创新奖的说明里写得很直接：“单纯堆砌图片或文字不构成突出表现”。所以我们给自己定的做法是：**每条史料都要落到一条规则上**，读剧情只是顺带。

## 永昌堡的形制 → 地图

书里写永昌堡“设城门四座、水门四座、敌台十二座，东门建有瓮城；引水入堡形成上河与下河”。游戏地图照此布置：四座城门可以开关，十二座敌台就是玩家能安排守城单位的十二个位置，两条河穿过四座水门〔C16〕。东门的瓮城不只是画出来：瓮城等于两道门，所以东门比其他门耐砸 1.6 倍〔C17〕。

## 史事 → 三个夜晚

- 第一夜，嘉靖三十八年（1559）：王沛、王德前一年殉国，乡兵流动作战护不住乡里，于是筑堡；书里说“在工程最艰难的时刻，倭寇突至”。这一夜是教学关。
- 第二夜，崇祯五年（1632）：海盗刘香围攻，王至彪率义师与巡检司官兵共同御敌。敌人更多，从北、中、南三处登陆点上岸〔C11〕。
- 第三夜，顺治五年（1648）：何兆龙引海盗船千余来犯，邻近堡所相继失守，唯永昌堡严防八十余日，“远近避乱我堡者何止万人”。这一夜山寇从西边大罗山方向下来，投奔的百姓也是三夜里最多的〔C11〕。

每条史实在游戏里都标了出处编号，对应 `docs/文化资料与出处.md`〔C11〕。

## 寓兵于民、屯田 → 资源

汤和在沿海推行“寓兵于民”，永昌堡“堡内规划百余亩农田，战时可供自给”。游戏里的资源叫“民力”，只有两个来源：迎进城的百姓，和堡内屯田（每隔一段时间自动增加）。打退敌人不给资源——守城靠的是人，不是战利品〔C16〕。

## 拼字龙灯 → 舞龙显字

素材包里的文稿写，拼字龙灯“龙头、龙尾与七节龙身各自独立”，舞动时“通过调整节间距，可拼出‘天下太平’等吉祥字样”；原先只有红、黄两支龙队，如今有红、黄、蓝、绿、黑五支〔C11〕。

我们把它做成一个描字小游戏：九节的龙跟着鼠标走〔C17〕，玩家按笔顺描字。每守住一夜描一个字，红龙描“天”、黄龙描“下”、蓝龙描“太”，终章绿龙描“平”，最后五龙同台拼出“天下太平”〔C11〕。笔顺用汉典的笔顺编号核对过〔C12〕。

## 没放进游戏的东西

资料包里的照片和书里的插图都没有用：来源授权不清楚，而且照片放进游戏也只是“贴在墙上”。终章引用了宁村二月二拦街福和汤公百家宴“象征守望同心”的说法〔C11〕，作为“守·望”的另一种解释：守，是守住城门；望，是望见彼此。
